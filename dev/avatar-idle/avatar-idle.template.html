方案说明

候选实现分三层。角色：.avatar-body 包裹层承载呼吸（避免与插件定位 transform 冲突），.avatar-fidget 内层承载偶发动作；武器/盾牌/头发以滞后相位小幅摆动形成跟随感；睡眠时身体静止、zzz 缓慢上浮。材质与落地：高光用同一张素材 PNG 作 mask-image，只扫过装备像素；基座影子与身体反相呼吸，产生重量感。氛围与纵深：星光/轨道/浮尘为纯 CSS 循环；指针视差用独立 translate 属性叠加，不触碰定位 transform。系统"减少动态效果"时全部停用。本页所有动画代码仅存在于 dev 预览，插件源码未改动。素材与文本归属见 THIRD-PARTY-NOTICES。
