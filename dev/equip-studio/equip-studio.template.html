背包选择 → 穿戴/卸下 → Avatar 即时重绘的完整闭环。内置模拟网关，可演练"明确拒绝"与"结果不确定→暂停→人工核对"的安全语义。

空闲

角色与物品素材来自 Habitica CDN，需联网加载；离线时显示占位符。虚构账户 · 本地模拟请求 · 不保存任何数据
方案说明

本原型复用插件真实的 inventoryItems / avatarLayers / assetURLPOST /user/equip/{type}/{key}（战斗装备槽：weapon / shield / head / armor）。模拟网关演练三种结果：成功→本地变更+即时重绘；明确拒绝→清除标记可重试；结果不确定→本地状态不变、暂停后续操作、绝不自动重发，需人工核对解除——与插件 executeAction 的持久化安全契约一致。未来接入真实请求时，只需把模拟网关换成客户端 equip 方法并复用同一工作流。装扮（costume）槽位与 headAccessory / eyewear / back 等扩展槽不在本原型范围。本页所有代码仅存在于 dev 预览，插件源码未改动。素材与文本归属见 THIRD-PARTY-NOTICES。
