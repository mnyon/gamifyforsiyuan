方案说明

角色欢呼：用独立 translate/rotate CSS 属性叠加在角色定位 transform 之上，无需包裹层；武器绕握持点微扬，宠物延迟 50ms 弹起；900ms 节流防止离线队列补发时叠跳。进度氛围：复用光标系统已缓动的 approach 值驱动场景 CSS 变量，基座/轨道的基色与插件逐位一致，0 进度时零差异。彩蛋：活跃写作时长满 60 秒后"上膛"，随机 15–60 秒后触发流星（70%）或月晕（30%），触发后清空累计并冷却 2 分钟——稀有、不可预期、不可刷；页面隐藏或系统减少动态效果时不触发。月晕为三层结构：比月亮大数倍的乳白弥散光斑（blur 朦胧化）、延迟浮现的外缘光环、月亮本体增亮，暖月光渐隐入夜色紫调。预览按钮仅供评估，正式版本无此入口。本页所有代码仅存在于 dev 预览，插件源码未改动。
