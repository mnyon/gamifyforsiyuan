# Gamify for SiYuan

你的 Habitica 角色，与你的笔记同行。

## 安装与连接

桌面端点击右下角 Habitica 图标；手机端使用顶部入口。在设置中填写 Habitica User ID 和 API Token，连接后可查看角色、生命值和金币。金币等实际收益由 Habitica 计算。

先禁用已有插件，再用安装包中的文件替换工作空间 `data/plugins/gamify-for-siyuan/` 下的文件，最后重新启用插件。已有进度会保留。

日常界面不展示目标、规则或行为建议。

编辑时使用荧光竖线表达微光：柔和呼吸、光晕凝聚、上行暖光、淡紫回应、停顿余温与恢复苏醒。竖线跟随文字插入位置，不跟随鼠标，不使用圆圈或短光痕。暂停后逐渐淡出；输入法组合输入、选择文本、失焦、减少动态效果或插件关闭时保留或恢复原生插入符及选择手柄。

在编辑与维护奖励确认结算时，保留金色上行光，并显示与 TODO 相同的金币数值及飞金币动画。逐渐泛金仍只表示接近奖励。减少动态效果时显示数值，不播放飞金币动画。

## 模拟奖励包

`dist/package-test.zip` 为独立模拟构建，不连接 Habitica，不发放真实奖励。统计和模拟奖励保存在当前设备的独立记录中。可以直接在正常编辑过程中体验，也保留原有模拟按钮。对笔记的实际编辑仍会正常保存。

`dist/package.zip` 为可连接 Habitica 的构建。两种构建使用相同插件 ID，替换使用，不能并排安装。模拟期间的记录不会补入正式进度。

## 数据与连接信息

正式进度保存在工作空间 `data/storage/petal/gamify-for-siyuan/progress.json`。统计保留日期、块标识、数量、时间和奖励状态，不另存笔记正文。运行时文本比较只在内存中完成；笔记正文不会发送给 Habitica。角色图像来自 Habitica 官方素材服务器。

凭据默认只保存在当前设备。可选的「随思源同步连接信息」会将 User ID 和 API Token 明文保存在工作空间 `connection.json` 文件中，随思源同步。关闭并保存可清空共享文件，但不会撤销令牌，也不会清除其他设备缓存及备份。

桌面和手机均可使用。当前不处理多设备并发编辑与合并；换设备前完成思源同步，收到其他设备进度更新后需重新启用插件。窗口锁仅防止同一浏览器环境的多个窗口同时写入。

专用 Habitica 习惯为「在思源完成任务」。请保留其琐事难度、仅正向设置，不要手动加分，以便核对到账状态。离线记录保留；结果不确定的请求不会自动重发，可在角色卡中核对。

## 角色、技能、商店与背包

角色显示当前坐骑和宠物，并显示生命、经验、法力及金币。职业技能使用官方图标与说明。所有职业中，需指定任务或成员的技能均禁用并说明原因；本插件仅施放无需选择目标的自身或队伍技能。等级不足、法力不足和关闭职业系统时也不能施放。施放前会显示确认。

场景会回应你的投入：奖励到账且卡片可见时，角色小跳、武器微扬、宠物同步弹起（900 毫秒节流，离线补发不会叠跳）；基座光晕与轨道环微光随奖励进度增强，0 进度时与原场景一致；持续真实编辑约 60 秒后，场景可能随机出现流星或月晕彩蛋（随机延迟 15–60 秒，触发后冷却 2 分钟，页面隐藏时不触发）。以上全部遵循系统"减少动态效果"偏好，不新增后台轮询。

角色有待机动画：身体缓慢呼吸浮动，武器、盾牌、头发/头饰以滞后相位小幅随动，装备表面偶有高光扫过；基座影子与身体反相呼吸，星光闪烁、轨道缓转、浮尘上升；桌面端指针移动时场景分层微移产生纵深（触屏不启用）。在旅馆休息时角色保持静止，仅 zzz 缓慢上浮。光标余晖按奖励来源着色：照料旧文档的维护类奖励为紫色，新进展奖励为金色；输入与删除共用绿色基色，不评判动作方向。

旅人商店读取官方精选、当前季节与可购买装备，保留官方名称、价格及说明。仅支持金币购买；宝石商品需在 Habitica 官方商店购买。生命药水购买后立即使用；魔法宝箱解锁资格由账户决定。购买前检查余额、资格和已拥有状态，并显示确认。开箱动画只展示服务器实际返回的装备、宠物食物或经验，可跳过；遵循音效设置和减少动态效果偏好，不生成额外随机奖励。

背包展示真实持有装备、食物、宠物蛋、孵化药水与任务卷轴。可分类、查看数量、已装备标记和详情。持有装备可在详情中穿戴或卸下（官方 `/user/equip/equipped/{key}` 端点，同一端点切换穿卸），成功后角色外观即时重绘；穿戴前检查持有状态并显示确认，跨职业装备与装扮模式会给出提示。战斗装备变化在装扮（costume）模式下不改变外观。食物、蛋与药水当前不提供使用或出售。

角色与背包共享账户快照，普通读取缓存 60 秒，手动刷新至少间隔 15 秒；商店缓存 5 分钟，公开物品说明按语言在本机缓存 24 小时。并发读取合并，不新增后台轮询。重要写操作前会读取最新账户，奖励结算仍使用最新余额，不依赖显示缓存。限流遵从 Retry-After，失败后延后请求。

购买、施放和装备只在已连接的主窗口执行，与奖励结算互斥。请求超时或结果无法解析时不会自动重发，并在本机保留未确认标记，重启后继续暂停这些操作。请先在 Habitica 核对结果，再点击「已在 Habitica 核对，解除操作暂停」。解除暂停只刷新状态，不重发上次操作。公开内容缓存不含凭据，账户快照仅存于当前客户端内存。
